# DYKiller

> DY测试版本 39.8.0

> 本项目旨在补充和修复 图层、优化、DYYY、DYYY++ 等项目中缺失或已失效的功能，原则上不重复实现已有功能。如有其他需求，开发者可自行 Fork 本项目，并参考“致谢”中列出的相关项目进行修复或扩展。

## 现有功能

- 悬浮玻璃底栏-BETA（仅 iOS 26+）：把抖音底栏换成系统液态玻璃底栏，可选清透材质（默认磨砂），测试功能，可能不稳定。
- 评论区液态玻璃-BETA（仅 iOS 26+）：默认使用系统模糊玻璃，可切换清透玻璃（可读性极差）；半屏时保留弹幕。
- 视频全屏：各页视频与图文统一铺满整屏，文案与进度条保持原位。
- 移除评论区底栏：隐藏评论区常驻输入栏，回复时临时恢复。
- 作品详情页底栏移除：隐藏作品详情页底部的输入栏。
- 移除关注按钮：隐藏头像下方的关注加号。
- 移除音乐信息栏：隐藏文案下方的「去汽水听」。
- 个人主页清理：移除作品列表下方的发作品引导。
- 调试工具：开启全局调试入口，支持运行时信息导出。

## 项目架构


```text
DYKiller/             
├── DYKiller.plist             
├── Makefile                   
├── control                    
└── src/
    ├── Debug/                 # 调试入口、运行时信息采集与导出
    ├── FLEX/                  # 调试导出所需的压缩与类信息辅助工具
    ├── Features/              # 独立功能实现
    │   ├── ChatVideo/         # 作品详情页底栏功能
    │   ├── Comment/           # 评论面板相关功能
    │   ├── Feed/              # 视频流
    │   ├── Interaction/       # 页面交互相关功能
    │   ├── Profile/           # 个人主页相关功能
    │   ├── TabBar/            # 底栏功能
    │   └── VideoFullscreen/   # 视频几何拦截、视频表撑高与视频页修饰
    ├── Headers/               # 抖音私有类前向声明与必要接口声明
    ├── Settings/              # 抖音设置入口注入与功能开关注册框架
    └── Shared/                # 共享开关、版本宏与无状态工具函数
```
